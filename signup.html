Autonomous GitHub ResolverTerms · Privacy

From sign-up to your first pull request.

Three steps, and you stay in control of every change that reaches your repository.

  1. Connect GitHub

    Resolver lists your repositories and their open issues. It only ever proposes changes as a pull request.

  2. Create your organization

    You become its Owner. Invite teammates by GitHub username and give them Member or Admin access.

  3. Start your first run

    Pick a repository, an open issue and a model, then watch every step live.

Sealed by default. Every run happens in a read-only, non-root container with --network none. No internet, no access to your machine.
