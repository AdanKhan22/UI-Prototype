Resolver theme

The visual system for Autonomous GitHub Resolver. A run is kept like a signed lab record: nothing is erased, a rolled-back step is struck once and annotated, and a person countersigns risky changes. All sample data on this page is illustrative.

Step record

The signature. Steps sit on 40px ruled rows with a red margin line. A rolled-back step is never hidden: its command is struck once in correction red and annotated with the checkpoint it returned to and why. The current step sits on a blue-tint band.

Review and countersign

When the gate pauses a run, the person reviewing it sees what was flagged, where it came from and the exact diff, then signs. The agent's own line is filled in; the witness line waits for a human.
